# Персональный сайт-портфолио

Элегантный, адаптивный и современный сайт-портфолио, разработанный для демонстрации премиальных проектов по веб-разработке и UI-дизайну. Проект выполнен в глубокой темной теме с теплыми закатными градиентами, делает упор на плавные интерактивные элементы, эффекты глассморфизма и безупречный пользовательский опыт на любых устройствах.

## Особенности проекта

* **Премиальный UI/UX:** Строгий темный дизайн с акцентной янтарной подсветкой и качественной типографикой.
* **Глассморфизм:** Фиксированная шапка сайта и главная карточка с эффектом матового стекла (`backdrop-filter`).
* **Интерактивная сетка:** Кликабельные карточки проектов с эффектами увеличения при наведении, объемными тенями и строгими пропорциями 16:10.
* **Плавные анимации:** Элементы плавно появляются на экране (Fade-in), а секции бесшовно перетекают друг в друга благодаря сложным градиентам.
* **Полная адаптивность:** Идеальное отображение на десктопах, планшетах и мобильных телефонах с использованием CSS Grid и Flexbox.

## Технологии

* **HTML5:** Семантическая разметка.
* **CSS3:** Flexbox, CSS Grid, медиазапросы, кастомные анимации и сложные градиенты (linear/radial).
* **JavaScript (Vanilla):** Нативный JS для легковесной интерактивности.
* **Сборка:** Vite для быстрой локальной разработки и оптимизации продакшен-кода.

## Структура файлов

* `index.html` — Главный HTML-документ.
* `style.css` — Все стили проекта.
* `img/` — Директория с изображениями (фоны, мокапы проектов).

## Как запустить

1. Скачайте или клонируйте этот репозиторий на свой компьютер.
2. Установите зависимости, выполнив команду `npm install`.
3. Запустите локальный сервер командой `npm run dev`.
4. Соберите проект для деплоя с помощью `npm run build`.
