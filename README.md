# Personal Portfolio Website

An elegant, responsive, and modern personal portfolio designed to showcase premium web development and UI design projects. Built with a deep dark theme and warm sunset gradients, the project emphasizes smooth interactive elements, glassmorphism effects, and a flawless user experience across all devices.

## Project Features

* **Premium UI/UX:** Deep dark design (`#080808`) with ambient amber glows and high-quality typography.
* **Glassmorphism:** Fixed navigation bar and hero cards with frosted glass effects (`backdrop-filter`).
* **Interactive Grid:** Clickable project cards with scale transitions, floating shadows, and strict 16:10 aspect ratios.
* **Smooth Animations:** Elements fade in smoothly on scroll (Fade-in) and feature seamless gradient transitions between sections.
* **Fully Responsive:** Perfect rendering on desktops, tablets, and mobile phones using CSS Grid and Flexbox.

## Technologies

* **HTML5:** Semantic markup.
* **CSS3:** Flexbox, CSS Grid, media queries, custom animations, and complex radial/linear gradients.
* **JavaScript (Vanilla):** Lightweight DOM manipulation and interactivity.
* **Build Tool:** Vite for fast local development and optimized production builds.

## File Structure

* `index.html` — Main HTML document.
* `style.css` — All project styles.
* `img/` — Directory for images (backgrounds, project mockups).

## How to Run

1. Clone this repository to your local machine.
2. Install dependencies using `npm install`.
3. Start the local development server using `npm run dev`.
4. Build for production using `npm run build`.
